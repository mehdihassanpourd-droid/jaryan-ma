# آزمایش پنل مدیریت روی گوشی اندروید با GitHub Codespaces

این راهنما برای **آزمایش موقت** پنل مدیریت جریان ما از روی گوشی است؛ بدون رایانه، بدون سرور و بدون هزینه. همان کد واقعی اجرا می‌شود: PostgreSQL 16 واقعی، ورود با گذرواژه **و** کد دومرحله‌ای (TOTP) اجباری، کوکی امن و HTTPS معتبر.

> این محیط **تولیدی نیست**: داده‌هایش موقتی است، فروشگاه عمومی را تغییر نمی‌دهد، چیزی منتشر یا مستقر نمی‌کند و نباید داده یا مشتری واقعی در آن بگذارید.

## پیش از شروع (یک بار)
1. حساب GitHub را در مرورگر کروم گوشی وارد کنید.
2. در تنظیمات صورتحساب (Billing) **هیچ روش پرداختی اضافه نکنید**. سهمیهٔ رایگان حدود ۱۲۰ ساعت‌هسته در ماه است (برای ماشین ۲ هسته‌ای حدود ۶۰ ساعت). اگر تمام شود، GitHub فقط اجازهٔ ساخت یا ازسرگیری را نمی‌دهد و پولی کسر نمی‌شود.
3. در تنظیمات Codespaces (github.com/settings/codespaces): «Default idle timeout» روی ۳۰ دقیقه و «Default retention period» روی ۱ روز بماند یا کمتر شود.

## مراحل راه‌اندازی
۱. در کروم به **github.com/codespaces** بروید. بهتر است از منوی ⋮ گزینهٔ «Desktop site» را روشن کنید و گوشی را افقی بگیرید.

۲. **New codespace** را بزنید و این‌ها را انتخاب کنید:
   - Repository: `mehdihassanpourd-droid/jaryan-ma`
   - Branch: `main` (تا زمانی که این تغییر ادغام نشده: `claude/codespaces-admin-test`)
   - Machine type: **2-core**

۳. صبر کنید تا ساخته شود (بار اول چند دقیقه). نصب خودکار انجام می‌شود و در پایان پیام «آماده است» را می‌بینید. اگر دیدید نشد، در ترمینال این را اجرا کنید: `npm run codespace:setup`

۴. در ترمینال پایین صفحه، مدیر را بسازید (ایمیل خودتان را بگذارید):
   ```
   npm run codespace:admin -- you@example.com
   ```
   - گذرواژه را دو بار وارد کنید (هنگام تایپ نمایش داده نمی‌شود؛ دست‌کم ۱۲ نویسه و یکتا).
   - برنامه یک **Secret** نشان می‌دهد. آن را نگه دارید (با لمس طولانی کپی کنید).
   - در برنامهٔ احراز هویت (Google Authenticator، Aegis، 2FAS …): «افزودن حساب» ← «Enter a setup key» ← نام دلخواه، همان Secret، نوع «Time based».
   - کد ۶ رقمی برنامه را در ترمینال بزنید تا تأیید شود.

۵. برنامه را اجرا کنید:
   ```
   npm run codespace:start
   ```
   نشانی خصوصی چاپ می‌شود (مثل `https://…-3001.app.github.dev/admin/`). می‌توانید آن را از تب **Ports** هم باز کنید (آیکن کره‌ی زمین).

۶. نشانی را در **کروم** باز کنید. اگر GitHub ورود خواست، وارد شوید. سپس در صفحهٔ «ورود به مدیریت جریان ما» ایمیل، گذرواژه و کد ۶ رقمی را بزنید. هر کد فقط یک بار پذیرفته می‌شود؛ اگر رد شد، کد بعدی را صبر کنید.

۷. نصب مثل برنامه: منوی ⋮ کروم ← «Install app» یا «Add to Home screen».

## چه چیزهایی را آزمایش کنیم
دسته‌بندی بسازید ← محصول بسازید ← تصویر با «گرفتن عکس» (دوربین) و «انتخاب از گالری» ← گونه و موجودی ← قیمت‌های بزرگ ← سئو ← انتشار ← کپی و بایگانی ← خروجی و ورودی CSV ← حساب‌های `editor` و `viewer` (با `npm run codespace:admin -- test@example.com viewer`) برای دیدن محدودیت نقش‌ها.

## پایان کار
1. در ترمینال `Ctrl+C` (یا Codespace را Stop کنید).
2. **حذف کامل:** github.com/codespaces ← منوی ⋯ کنار Codespace ← Delete. همهٔ داده‌ها (پایگاه داده، تصاویر، حساب‌ها) پاک می‌شود. دفعهٔ بعد حساب جدید بسازید.

## نکات امنیتی
- **پورت را هرگز Public نکنید.** حالت پیش‌فرض Private است: فقط با ورود به حساب GitHub شما باز می‌شود و پنل هنوز گذرواژه و کد دومرحله‌ای می‌خواهد. اسکریپت شروع هم تلاش می‌کند پورت را خصوصی نگه دارد و اگر نشد هشدار می‌دهد.
- نشانی را با کسی به اشتراک نگذارید و گذرواژه یا Secret را در چت یا کد ننویسید.
- از گذرواژه‌ای که جای دیگر استفاده می‌کنید استفاده نکنید.
- هیچ حساب پیش‌فرض یا ورود آزمایشی وجود ندارد؛ بدون کد دومرحله‌ای ورود ممکن نیست.
- بعد از هر آزمایش Codespace را حذف کنید.

## عیب‌یابی
| مشکل | راه‌حل |
|---|---|
| «این دستور فقط داخل Codespaces اجرا می‌شود» | دستورها را داخل ترمینال Codespace بزنید، نه جای دیگر. |
| «هنوز مدیری ساخته نشده» | ابتدا `npm run codespace:admin -- you@example.com` را بزنید. |
| پیام «این درخواست از آدرس مجاز ارسال نشد» (bad_origin) | پنل را حتماً با نشانی چاپ‌شده توسط `codespace:start` باز کنید. |
| بعد از ۳ ساعت دوباره صفحهٔ GitHub می‌آید | عادی است؛ دوباره وارد GitHub شوید. |
| Codespace خاموش و دوباره روشن شد | داده‌ها می‌مانند؛ فقط `npm run codespace:start` را دوباره بزنید. |
| گزینهٔ نصب برنامه نمی‌آید | یک بار صفحه را تازه کنید و چند ثانیه صبر کنید؛ سپس از منوی کروم «Install app» را بزنید. |
| ترمینال روی گوشی سخت است | فقط دو فرمان لازم است. در صورت نیاز می‌توان از Termux با SSH استفاده کرد. |

## این محیط چه چیزی نیست
نمونهٔ سرور ایران نیست و دامنه، TLS نهایی، ذخیره‌ساز S3 و پشتیبان‌گیری واقعی را آزمایش نمی‌کند؛ این‌ها در مرحلهٔ سرور تولیدی بررسی می‌شوند (ADMIN-APP.md و SELF-HOSTING.md). انتشار محصول در اینجا فقط روی دیسک همین Codespace می‌نویسد و فروشگاه عمومی را بازسازی نمی‌کند.
