# راه‌اندازی پنل مدیریت روی گوشی اندروید (GitHub Codespaces)

این راهنما برای **آزمایش موقت** پنل مدیریت جریان ما از روی گوشی است؛ بدون رایانه، بدون ترمینال، بدون سرور و بدون هزینه. همان کد واقعی اجرا می‌شود: PostgreSQL 16 واقعی، ورود با گذرواژه **و** کد دومرحله‌ای (TOTP) اجباری، کوکی امن و HTTPS معتبر.

> این محیط **تولیدی نیست**: داده‌هایش موقتی است، فروشگاه عمومی را تغییر نمی‌دهد، چیزی منتشر یا مستقر نمی‌کند و نباید داده یا مشتری واقعی در آن بگذارید.

## پیش از شروع (یک بار)
1. در کروم گوشی وارد حساب GitHub شوید.
2. در تنظیمات صورتحساب (Billing) **هیچ روش پرداختی اضافه نکنید**. سهمیهٔ رایگان حدود ۱۲۰ ساعت‌هسته در ماه است (برای ماشین ۲ هسته‌ای حدود ۶۰ ساعت). اگر تمام شود، GitHub فقط اجازهٔ ساخت یا ازسرگیری را نمی‌دهد و پولی کسر نمی‌شود.
3. در github.com/settings/codespaces «Default idle timeout» روی ۳۰ دقیقه و «Default retention period» روی ۱ روز بماند.

## مراحل (فقط لمس، بدون تایپ دستور)
۱. این پیوند را در کروم باز کنید: **https://codespaces.new/mehdihassanpourd-droid/jaryan-ma** و در صفحهٔ باز شده گزینه‌ها را بررسی کنید: شاخهٔ `main` و ماشین **2-core**؛ سپس «Create codespace» را بزنید.

۲. صبر کنید (بار اول چند دقیقه). همهٔ کارها خودکار انجام می‌شود: نصب PostgreSQL، ساخت پایگاه داده، ساخت برنامهٔ مدیریت و اجرای آن. لازم نیست ترمینال را باز کنید.

۳. وقتی آماده شد، GitHub اعلانی با این مضمون نشان می‌دهد: «Your application running on port 3001 is available». روی **Open in Browser** بزنید. اگر اعلان را ندیدید: تب **Ports** (کنار Terminal) ← ردیف «Jaryan admin (private)» ← آیکن کرهٔ زمین.

۴. اگر GitHub ورود خواست، وارد شوید (پورت خصوصی است و فقط برای حساب شما باز می‌شود).

۵. صفحهٔ **«ساخت مدیر اول»** باز می‌شود (در بار اول همین صفحه می‌آید و بعد از ساخت اولین مدیر برای همیشه بسته می‌شود):
   - ایمیل و گذرواژه‌ای یکتا و دست‌کم ۱۲ نویسه وارد کنید و «ادامه» را بزنید.
   - دکمهٔ **«افزودن به برنامهٔ احراز هویت»** را بزنید تا Google Authenticator/Aegis/2FAS حساب را اضافه کند. اگر باز نشد، «کپی کلید» را بزنید و در برنامه «Enter a setup key» (زمان‌محور) را انتخاب کنید و کلید را بچسبانید.
   - کد ۶ رقمی برنامه را وارد کنید و «ساخت مدیر» را بزنید. بدون این کد، مدیر ساخته نمی‌شود.

۶. صفحهٔ ورود می‌آید: ایمیل، گذرواژه و یک کد **تازه** (هر کد فقط یک بار پذیرفته می‌شود؛ اگر رد شد کد بعدی را صبر کنید) را وارد کنید.

۷. نصب مثل برنامه: منوی ⋮ کروم ← «Install app» یا «Add to Home screen».

## چه چیزهایی را آزمایش کنیم
دسته‌بندی بسازید ← محصول بسازید ← تصویر با «گرفتن عکس» (دوربین) و «انتخاب از گالری» ← گونه و موجودی ← قیمت‌های بزرگ ← سئو ← انتشار ← کپی و بایگانی ← خروجی و ورودی CSV.

## پایان کار
Codespace را از github.com/codespaces ← منوی ⋯ ← **Delete** حذف کنید. همهٔ داده‌ها (پایگاه داده، تصاویر، حساب‌ها) پاک می‌شود. دفعهٔ بعد دوباره «ساخت مدیر اول» را می‌بینید.

## نکات امنیتی
- **پورت را هرگز Public نکنید.** حالت پیش‌فرض Private است: فقط با ورود به حساب GitHub شما باز می‌شود و پنل هنوز گذرواژه و کد دومرحله‌ای می‌خواهد. برنامه هم تلاش می‌کند پورت را خصوصی نگه دارد.
- «ساخت مدیر اول» فقط وقتی هیچ مدیری وجود ندارد باز است، فقط در محیط آزمایشی کار می‌کند (سرور تولیدی آن را رد می‌کند)، رمز و کد دومرحله‌ای را اجباری می‌کند و هرگز حساب دوم نمی‌سازد.
- نشانی را با کسی به اشتراک نگذارید؛ گذرواژه یا کلید را در چت یا کد ننویسید؛ گذرواژه‌ای که جای دیگر استفاده می‌کنید نگذارید.
- هیچ حساب پیش‌فرض یا ورود آزمایشی وجود ندارد.

## عیب‌یابی
| مشکل | راه‌حل |
|---|---|
| صفحه «پنل مدیریت هنوز ساخته نشده» نشان می‌دهد (503) | Codespace را Stop و دوباره Start کنید؛ ساخت خودکار انجام می‌شود. |
| صفحه باز نمی‌شود یا اعلان نیامد | تب Ports را باز کنید؛ اگر پورت 3001 نیست، Codespace را Stop و Start کنید تا برنامه دوباره بالا بیاید. |
| پیام «این درخواست از آدرس مجاز ارسال نشد» | پنل را فقط با آدرس پورت 3001 همین Codespace باز کنید (از تب Ports). |
| بعد از ۳ ساعت دوباره صفحهٔ GitHub می‌آید | عادی است؛ دوباره وارد GitHub شوید. |
| گزینهٔ نصب برنامه نمی‌آید | صفحه را یک بار تازه کنید و چند ثانیه صبر کنید؛ سپس از منوی کروم «Install app» را بزنید. |

## فقط برای حالت پیشرفته (اختیاری، ترمینال)
برنامه خودکار اجرا می‌شود؛ این‌ها فقط در صورت نیاز است: `npm run codespace:up` (اجرا/نمایش نشانی)، `npm run codespace:down` (توقف)، `npm run codespace:logs` (گزارش)، `npm run codespace:admin -- you@example.com [owner|editor|viewer]` (افزودن حساب دیگر با همان قوانین).

## این محیط چه چیزی نیست
نمونهٔ سرور ایران نیست و دامنه، TLS نهایی، ذخیره‌ساز S3 و پشتیبان‌گیری واقعی را آزمایش نمی‌کند؛ این‌ها در مرحلهٔ سرور تولیدی بررسی می‌شوند (ADMIN-APP.md و SELF-HOSTING.md). انتشار محصول در اینجا فقط روی دیسک همین Codespace می‌نویسد و فروشگاه عمومی را بازسازی نمی‌کند.
