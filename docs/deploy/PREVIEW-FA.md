# پیش‌نمایش عمومی جریان ما

**نشانی دائمی:** https://jaryan-ma.pages.dev

این نشانی همیشه آخرین نسخهٔ شاخهٔ `main` را نشان می‌دهد. هر بار که چیزی در `main` ادغام شود، به‌صورت خودکار ساخته و منتشر می‌شود (بدون هیچ کاری از شما). برای هر Pull Request هم یک نشانی پیش‌نمایش جدا (`pr-<شماره>.jaryan-ma.pages.dev`) ساخته می‌شود.

## چطور مطمئن شویم نسخهٔ آخر دیده می‌شود؟
- پس از هر انتشار، گردش‌کار خودش سایت زنده را باز می‌کند و فایل `https://jaryan-ma.pages.dev/build-info.json` را می‌خواند. اگر شناسهٔ commit با نسخهٔ تازه یکی نباشد، یا صفحه‌های اصلی جواب ندهند، اجرا **قرمز** می‌شود و یک Issue با برچسب `deployment-failure` باز می‌شود.
- شما هم می‌توانید همین نشانی را در مرورگر گوشی باز کنید و با شناسهٔ commit آخر در GitHub (Actions ← Cloudflare Pages) مقایسه کنید.
- انتشار نهایی فقط وقتی انجام می‌شود که همهٔ بررسی‌های آن commit سبز باشند.

## کدام صفحه‌ها را روی اندروید می‌توانید امتحان کنید؟
| صفحه | وضعیت |
|---|---|
| صفحهٔ اصلی، مجموعه‌ها، آثار نمونه، داستان، تماس | کامل (محتوا «نمونه» است) |
| صفحهٔ هر مجموعه (`/category/...`) | کامل، از کارت مجموعه‌ها قابل‌رسیدن است |
| صفحهٔ هر اثر (`/products/...`) | کامل، از کارت اثر قابل‌رسیدن است |
| سبد خرید، تکمیل سفارش، سفارش‌های من | باز می‌شوند ولی فقط توضیح می‌دهند که به فروشگاه متصل نیستند |
| صفحهٔ مدیریت (ادمین) | **در پیش‌نمایش عمومی وجود ندارد** (عمدی) |

## چه چیزهایی فقط نمایشی (دمو) هستند؟
- همهٔ محصولات و دسته‌ها نمونه‌اند و برچسب «نمونه» دارند.
- قیمت‌ها اعلام نشده‌اند («قیمت به‌زودی اعلام می‌شود»)؛ قیمت ساختگی نمی‌گذاریم.
- هیچ سفارشی ثبت نمی‌شود، شمارهٔ سفارشی نشان داده نمی‌شود و پرداختی وجود ندارد.
- هیچ پیامکی ارسال نمی‌شود.
- صفحه‌ها برای موتورهای جستجو بسته‌اند (`noindex`).

## چه چیزهایی در پیش‌نمایش در دسترس نیستند و چرا؟
سفارش، موجودی، هزینهٔ ارسال، رهگیری، ورود با پیامک و پنل مدیریت به **سرور و پایگاه‌داده** نیاز دارند. پیش‌نمایش عمومی فقط فایل ثابت (استاتیک) است و عمداً سرور، پایگاه‌داده، رمز یا حساب مدیر ندارد؛ پس هیچ اطلاعات خصوصی یا امکان مدیریتی عمومی نمی‌شود. تست خودکار هم بررسی می‌کند که در فایل‌های منتشرشده پنل مدیریت، API یا رمز و کلیدی نباشد.

## برای امتحان کامل خرید، ارسال و پنل مدیریت
از محیط آزمایشی **Codespaces** استفاده کنید (راهنما: `docs/admin/CODESPACES-FA.md`): سرور و پایگاه‌دادهٔ واقعی با دادهٔ موقت، رایگان، فقط برای خود شما و روی گوشی اندروید. پرداخت و پیامک واقعی در آن هم غیرفعال است.
